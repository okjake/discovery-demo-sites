Rate & restriction sync

A public REST API for PMS partners

Our API is public and documented at docs.velada-demo.example. PMS partners read and write availability, rates and reservations, and subscribe to webhooks so changes arrive in real time.

POST /v2/properties/{id}/availability
PUT  /v2/properties/{id}/rates
GET  /v2/reservations?updated_since=…

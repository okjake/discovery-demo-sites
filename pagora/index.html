Two-way with your booking software

Pagora connects to your booking software in both directions: bookings come in, payment status goes back.

  • REST API to create payments, holds and payouts
  • Webhooks push payment status back to your booking software in real time
  • Reconciliation export per owner
  • PSD2 strong customer authentication
  • PCI DSS Level 1

An API and webhooks for software partners

Our API is documented at docs.pagora-demo.example. software partners create payments from a reservation, and Pagora calls back with every status change.

POST /v1/payments        { reservation_id, amount }
POST /v1/deposits/holds
POST /v1/payouts/splits
